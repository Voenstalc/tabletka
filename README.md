# Таблетка

Мобильное приложение-напоминалка о приёме лекарств. Работает офлайн, данные хранятся только на телефоне.

## Возможности

- Напоминания по расписанию: несколько раз в день, по дням недели, каждые N часов, курс с датами начала и конца.
- Кнопки прямо в уведомлении: «Принял», «Отложить», «Пропустить».
- Повторное напоминание, если приём не отмечен.
- Учёт остатка: списание дозы при отметке «Принял», ручное пополнение и исправление.
- Предупреждение, когда запаса хватает меньше чем на заданное число дней.
- История приёмов, процент соблюдения расписания за 7 и 30 дней, разбивка по лекарствам.
- Несколько профилей (например, для себя и родственника).
- Резервная копия в JSON: сохранить в файл и восстановить.
- Обновление приложения изнутри: подписанный манифест, проверка SHA-256 APK и системный установщик Android.
- Крупный шрифт, высокий контраст, большие кнопки — интерфейс рассчитан на пожилых людей.

## Запуск

```bash
cd app
npm install
npx expo start
```

Для разработки на телефоне нужен **development build**, а не Expo Go: приложение использует точные локальные уведомления, действия в уведомлениях и фоновое обновление расписания.

### Вариант 1. Локальная сборка (нужен Android Studio / Android SDK)

```bash
cd app
npx expo run:android
```

### Вариант 2. Сборка в облаке через EAS

```bash
cd app
npx eas-cli@latest login
npx eas-cli@latest build --profile preview --platform android
```

Готовый APK можно установить на телефон. Профиль `development` создаёт dev-клиент, `preview` — обычный APK для проверки, `production` — сборка для магазина.

Для iOS нужен Mac или сборка через EAS (`--platform ios`).

## Как устроены напоминания

- Уведомления планируются локально на 30 дней вперёд с запасом под лимит iOS (58 запланированных).
- При запуске приложения, изменении лекарств или настроек расписание пересоздаётся.
- Фоновая задача `expo-background-task` раз в несколько часов продлевает окно и проверяет остатки. Это страховка: основной механизм — уведомления ОС.
- На Android 12+ для точного времени нужно разрешение «Будильники и напоминания». Если его нет, система может доставить уведомление с задержкой; приложение подскажет включить разрешение в настройках.
- Остаток списывается только при явной отметке «Принял». Отсутствие отметки не уменьшает запас, но приём помечается пропущенным через 2 часа.

## Данные и приватность

Все данные лежат в SQLite на устройстве. Нет аккаунта и передачи данных о лекарствах. Проверка обновлений обращается только к серверу обновлений за подписанным манифестом и ничего о пользователе не отправляет. Резервная копия создаётся только по команде пользователя.

Обновления: «Настройки → Обновление приложения». Проверка выполняется при
запуске не чаще раза в сутки, скачивание — только по кнопке. Манифест и APK
проверяются по RSA-подписи и SHA-256; установку подтверждает Android.

GitHub ([Voenstalc/tabletka](https://github.com/Voenstalc/tabletka)) — только
исходный код. Файлы обновлений (подписанный `version.json` и APK) лежат на
VPS проекта и раздаются по HTTPS с приватным CA:
`https://48.102.177.243:8443/updates/tabletka/android/version.json`.

## Ограничения

- Приложение не заменяет врача и не проверяет совместимость лекарств.
- История рассчитывается по текущему расписанию. Изменение времени приёма не переписывает уже сохранённые отметки, но может изменить вид прошлых запланированных доз.
- Точность напоминаний зависит от настроек энергосбережения телефона и разрешений ОС.
